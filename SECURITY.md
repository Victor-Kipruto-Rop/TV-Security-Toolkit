# Security policy

## Scope
TV Security Toolkit is a defensive assessment tool. Use it only against devices and systems you own or have explicit authorization to test. The simulator and USB loopback adapter are intended for development and regression testing; they do not prove real-TV compatibility.

## Reporting a vulnerability
Please do not publish exploitable details or sensitive device data in a public issue. Contact the repository maintainer privately through the contact method available on the maintainer's GitHub profile, and include:
- affected version or commit;
- affected component and environment;
- minimal reproduction steps using a simulator where possible;
- expected and observed behavior;
- impact and any proposed mitigation.

Do not include credentials, production signing keys, personal data, or unredacted device identifiers. The project has no published guaranteed response-time SLA at this time.

## Supported versions
No formal release support window has been established. Confirm the latest repository state and disclose the exact version/commit when reporting an issue.
